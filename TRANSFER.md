# Запуск и перенос BLITZ

Для локального запуска следуйте README. Клонирование GitHub не переносит учётные записи, прогресс, ключи или владение размещённым сайтом.

В `.openai/hosting.json` указан существующий проект Sites. Для независимого сайта в другом аккаунте создайте отдельную копию исходников, удалите `project_id` **только в этой копии** и зарегистрируйте её через Sites как новый проект. Сохраните логическую привязку `DB`, примените все миграции из `drizzle/`, задайте собственный серверный `OPENAI_API_KEY` и выбранную модель. Старый сайт и его базу не изменяйте.

Новая база пустая: пользователь создаёт свой первый блиц. Готовый Python-маршрут в `data/python.json` оставлен для совместимости и тестов; он не назначается новым пользователям автоматически.

Данные D1 переносятся отдельно только при необходимости и с подтверждённым сопоставлением владельцев. В них входят аккаунты, сессии, курсы, попытки, проекты, чаты, карточки, расписание повторений и журнал XP. Не переписывайте владельцев записей массово. Сессии следует создавать заново после входа. Не помещайте дампы и секреты в GitHub.

История ChatGPT не входит в исходники. README и PROJECT_CONTEXT.md содержат достаточный контекст для разработки и проверки; они не заменяют архив переписки.
