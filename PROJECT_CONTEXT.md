# BLITZ — контекст проекта

Образовательная платформа команды Ctrl + C для любых тем. Пользователь задаёт цель, отвечает на три уточняющих вопроса и получает гибкую карту тем. Содержимое уроков создаётся по мере открытия. Фиксированных девяти уроков или трёх проектов больше нет; старые маршруты сохраняются.

Основной цикл: теория от основ и визуализации → тест → самостоятельный ответ → разбор ошибок → закрепление. Карточки проверяют воспроизведение по памяти и возвращаются по расписанию. Проекты добавляются по смыслу цели и оцениваются по критериям, без исполнения кода.

Общее направление: лаконичный русский интерфейс, блицы плитками, наглядная теория с раскрытием деталей, предметная независимость, аккаунты и сохранение данных. Опыт награждает учебные действия: журнал на сервере, защита от повторных наград, 30 рангов и отдельные направления. Формулы и ограничения — в README и lib/experience.ts.

Текущая версия: аккаунты с логином/паролем и ChatGPT, D1-хранилище, серверный OpenAI Responses API. Для запуска достаточно README: установка → setup → dev. Ключ не включён; локальная база создаётся автоматически.

Документация подготовки к проверке опирается на чат «Исследование проверки работ»: https://chatgpt.com/c/6ab3be1b-ffc8-83ed-b267-abf813745072. Общие требования к запуску и описанию учтены; соответствие бизнес-кейсу про каталог задач не заявляется. Не заменяйте образовательный продукт бизнес-каталогом без запроса автора.

Миграции в drizzle/; данные пользователей и секреты отдельно от исходников. Этот файл описывает текущий продукт, а не полную историю переписки. Проверенные сценарии и ограничения изложены в README.
