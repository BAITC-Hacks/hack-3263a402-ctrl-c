# BLITZ — контекст для продолжения

Платформа саморазвития: пользователь выбирает тему и проходит интенсивный маршрут по уровням. Проблема — разбросанные материалы и отсутствие структуры самостоятельного обучения. Основной цикл: теория со схемой и примером → практика → разбор конкретной ошибки → закрепление → мини-проект.

Пожелания автора: русский интерфейс, понятные объяснения, тесты, карточки, короткие ответы, контекстный ИИ-наставник, сохранение прогресса. При необходимости объяснять материал проще. Модель — gpt-6-astra, через серверный OpenAI Responses API.

Реализовано: Python, 3 уровня, 9 уроков, 3 мини-проекта; серверная проверка тестов и коротких ответов; история попыток, повторная практика, личный прогресс, хранение бесед; создание новых маршрутов и ИИ-наставник через API. Мини-проекты оцениваются моделью, код учащегося не исполняется. Сгенерированный материал требует проверки. API-ключ должен оставаться серверным секретом.

21 сентября 2026 прошли сборка, TypeScript, локальные интеграционные проверки и проверка интерфейса. Сайт опубликован через Sites. Прямой тест Astra тогда вернул credit_balance_exhausted; успешная работа живых ИИ-функций не подтверждена. Состояние баланса после той даты не проверено.

Этот документ — краткое описание контекста, а не полная история переписки. Полный профиль и детали реализации см. также README.md.
