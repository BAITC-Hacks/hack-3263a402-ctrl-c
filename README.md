# BLITZ

Hackathon team repository for Ctrl + C — BAITC-Hacks/hack-3263a402-ctrl-c.

Образовательная платформа для HackAlem: выбранная тема превращается в учебный блиц по уровням. Урок объединяет теорию, схему, пример, карточку и проверку. Ошибка сохраняет конкретное задание и ответ, открывается в контекстном чате и закрепляется отдельным упражнением. Каждые три урока — мини-проект.

## Образовательный трек

BLITZ — образовательная платформа. Главная показывает учебный курс, следующий урок и личный прогресс; программа курса открывается отдельным действием. Бизнес-каталог, роли заказчиков и команд в проект не входят.

Светлая тема: фон #F8FAFC, белые карточки, графитовый текст, синие названия курсов и навигация, изумрудный прогресс, янтарные ранги и награды, коралловые основные кнопки. Главная, уроки, практика ошибок, проекты и прогресс адаптированы под мобильный экран.

Геймификация связана с учёбой: 25 XP за новое верное решение, 150 XP за принятый проект, следующий уровень каждые 250 XP. Повторы не приносят дополнительный опыт. Четыре достижения открываются за первый ответ, десять решений, исправление ошибки и принятый проект.

Проверки: `node --test tests/game.test.mjs`, `npx tsc --noEmit`, `npm run build`.

## Что работает

- Готовый проверенный курс Python: три уровня, девять уроков, три проекта.
- Тесты и короткие ответы проверяются сервером по сохранённым ключам.
- Чтение теории и карточек не увеличивает прогресс. Для подтверждения навыка нужны верные основные ответы и закрепление ошибок.
- Прогресс, попытки, беседы, сданные проекты и сгенерированные курсы сохраняются в Cloudflare D1 и привязаны к идентификатору пользователя Sites.
- Через OpenAI Responses API с `gpt-6-astra`: создание нового тематического блица, диалог с наставником, разбор ошибок и оценка проектов. Ключ используется только на сервере.
- Первые уровни открыты для практики; теория будущих уровней доступна для просмотра.

## Запуск

Node.js 22.13 или новее. Установка: `npm run install:ci`. Скопируйте `.env.example` в `.env.local`, задайте свой `OPENAI_API_KEY`. Не добавляйте ключ в Git. Нужны API-кредиты и доступ проекта к модели. В окружении Sites ключ задаётся отдельно как секрет.

`npm run db:generate` создаёт миграции после изменения схемы. `npm run build` формирует Worker и `dist/server/wrangler.json`.

Локальная миграция (один раз для новой базы):

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_lethal_masked_marvel.sql
```

`npm run dev` запускает локальный сайт. Для локального входа используйте кнопку «Войти и сохранить прогресс»: portable starter имитирует учебную учётную запись. В опубликованном сайте аутентификацию выполняет Sites.

## Проверка

`npx tsc --noEmit` проверяет типы. На новом локальном хранилище `python3 tests/smoke.py` проверяет серверную оценку, восстановление попыток, изоляцию неавторизованного доступа, закрытые уровни, закрепление и условия сдачи проектов. Проверка создаёт данные только локально, для учётной записи предпросмотра. Её стоит выполнять на чистой тестовой базе; она не обращается к OpenAI.

## Границы первой версии

Проекты проверяются Astra по указанным критериям; код пользователя не выполняется. Оценку ИИ следует рассматривать как учебную обратную связь. Новый курс проверяется по структуре и корректности индексов ответов, но его фактическое содержание требует проверки. Короткие ответы сравниваются с заданным форматом, без семантической оценки. При ошибке API поля сохраняются на экране; готовый курс доступен без генерации.

Для защиты от случайного расхода установлено до 60 запросов к ИИ в день на пользователя. Доступ сайта по умолчанию закрыт владельцем; расширять аудиторию следует через настройки Sites.

## Устройство

`app/blitz-app.tsx` — интерфейс; `app/api/learn/route.ts` — операции; `lib/server.ts` — D1 и серверный вызов OpenAI; `lib/course.ts` — версия готового курса и отделение публичных заданий от ключей; `db/schema.ts` и `drizzle/` — хранилище и миграции.

Источники интеграции: [Responses API](https://developers.openai.com/api/docs/guides/text), [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra).
