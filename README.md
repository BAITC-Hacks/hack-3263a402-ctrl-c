# BLITZ

Hackathon team repository for Ctrl + C — BAITC-Hacks/hack-3263a402-ctrl-c.

Учебный раздел `/learn`: платформа саморазвития для HackAlem: выбранная тема превращается в учебный блиц по уровням. Урок объединяет теорию, схему, пример, карточку и проверку. Ошибка сохраняет конкретное задание и ответ, открывается в контекстном чате и закрепляется отдельным упражнением. Каждые три урока — мини-проект.

## Главная: бизнес-задачи и команды

Главная `/` — интерактивный прототип по [условиям кейса](https://docs.google.com/document/d/1lFWekP2SirFarATKkWa5neHNL5DlhjZKkUacvGyZk8k/preview). Белые карточки и фон Slate, синяя навигация, зелёный прогресс, янтарные награды и коралловые основные действия. Карта учебных миссий доступна отдельно в обучении.

- Черновик → минимум три уточняющих вопроса → редактируемая карточка → ручное подтверждение → публикация.
- Каталог отсортирован по готовности, с поиском и фильтрами темы/готовности. Низкий балл не блокирует публикацию и отклики.
- Оценка: контекст + потребность 20, данные 20, результат 15, успех 15, ограничения 10, пользователи 10, контакт + взаимодействие 10. Раздел заполнен при наличии от 10 символов в каждом поле (контакт от 5); подтверждение обязательно. Это прозрачная эвристика полноты, не оценка качества текста. Изменение пересчитывает сумму; сохранения не накапливают баллы.
- Диапазоны: 0–39 нужны уточнения, 40–69 рабочая, 70–89 готовая, 90–100 приоритетная.
- Пять синтетических задач, пять профилей и пять предложений. Бизнес может принять несколько команд, отклонить или отложить решение. Только подтверждённый этап принятого предложения даёт 100 XP, повторное подтверждение недоступно.

**Граница прототипа:** каталог, роли, предложения и XP хранятся в localStorage этого браузера. Переключатель ролей — демонстрация, не авторизация. Нет общей базы бизнес-задач, реальной отправки контактов или уведомлений. Все демонстрационные прототипы ведут на example.com. Для многопользовательского запуска нужны серверные права доступа, общая база и проверка этапов; учебный раздел уже имеет отдельный сервер D1.

### Демонстрационный AI-помощник

`lib/tasks.ts` экспортирует `analysisPrompt`, `clarifyDraft` и `parseAnalysis`. Локальная заглушка допустима условиями кейса: вход — черновик и поля карточки; выход — JSON `{questions: string[]}` с 3–7 вопросами по недостающим разделам. Помощник не заполняет факты за бизнес и не назначает команды. Пустой/короткий ввод блокируется, неправильный JSON или схема отклоняется. Интерфейс явно сообщает, что внешний AI API здесь не вызывается. Промпт и контракт готовы для будущего подключения модели; шаблонные вопросы не следует выдавать за модельную генерацию.

### Демонстрация за 5 минут

1. Покажите каталог и задачу с 20 баллами: она доступна для отклика.
2. В роли бизнеса нажмите «Описать задачу», введите потребность, получите вопросы. Добавьте название и известные сведения; неизвестные оставьте пустыми.
3. Проверьте предварительный рейтинг, подтвердите карточку и опубликуйте.
4. Переключитесь на команду, откройте задачу и отправьте идею, план, срок и ссылку на прототип.
5. В роли бизнеса откройте отклики, выберите команду. XP пока равен нулю. Опишите проверенный этап и подтвердите его: команда получает 100 XP.
6. Обновите страницу: локальные данные сохраняются. Откройте «Обучение», чтобы показать Python и учебный прогресс.

Архитектура прототипа: `app/task-board.tsx` — сценарии и локальное сохранение; `app/tasks.css` — адаптивный интерфейс; `lib/tasks.ts` — типы, правила, образцы и контракт помощника. Проверки: `node --test tests/game.test.mjs tests/tasks.test.mjs` и `npx tsc --noEmit`.

## Что работает

- Готовый проверенный курс Python: три уровня, девять уроков, три проекта.
- Тесты и короткие ответы проверяются сервером по сохранённым ключам.
- Чтение теории и карточек не увеличивает прогресс. Для подтверждения навыка нужны верные основные ответы и закрепление ошибок.
- Прогресс, попытки, беседы, сданные проекты и сгенерированные курсы сохраняются в Cloudflare D1 и привязаны к идентификатору пользователя Sites.
- Через OpenAI Responses API с `gpt-6-astra`: создание нового тематического блица, диалог с наставником, разбор ошибок и оценка проектов. Ключ используется только на сервере.
- Первые уровни открыты для практики; теория будущих уровней доступна для просмотра.

## Запуск

Node.js 22.13 или новее. Установка: `npm run install:ci`. Скопируйте `.env.example` в `.env.local`, задайте свой `OPENAI_API_KEY`. Не добавляйте ключ в Git. Нужны API-кредиты и доступ проекта к модели. В окружении Sites ключ задаётся отдельно как секрет.

`npm run db:generate` создаёт миграции после изменения схемы. `npm run build` формирует Worker и `dist/server/wrangler.json`.

Локальная миграция (один раз для новой базы):

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_lethal_masked_marvel.sql
```

`npm run dev` запускает локальный сайт. Для локального входа используйте кнопку «Войти и сохранить прогресс»: portable starter имитирует учебную учётную запись. В опубликованном сайте аутентификацию выполняет Sites.

## Проверка

`npx tsc --noEmit` проверяет типы. На новом локальном хранилище `python3 tests/smoke.py` проверяет серверную оценку, восстановление попыток, изоляцию неавторизованного доступа, закрытые уровни, закрепление и условия сдачи проектов. Проверка создаёт данные только локально, для учётной записи предпросмотра. Её стоит выполнять на чистой тестовой базе; она не обращается к OpenAI.

## Границы первой версии

Проекты проверяются Astra по указанным критериям; код пользователя не выполняется. Оценку ИИ следует рассматривать как учебную обратную связь. Новый курс проверяется по структуре и корректности индексов ответов, но его фактическое содержание требует проверки. Короткие ответы сравниваются с заданным форматом, без семантической оценки. При ошибке API поля сохраняются на экране; готовый курс доступен без генерации.

Для защиты от случайного расхода установлено до 60 запросов к ИИ в день на пользователя. Доступ сайта по умолчанию закрыт владельцем; расширять аудиторию следует через настройки Sites.

## Устройство

`app/blitz-app.tsx` — интерфейс; `app/api/learn/route.ts` — операции; `lib/server.ts` — D1 и серверный вызов OpenAI; `lib/course.ts` — версия готового курса и отделение публичных заданий от ключей; `db/schema.ts` и `drizzle/` — хранилище и миграции.

Источники интеграции: [Responses API](https://developers.openai.com/api/docs/guides/text), [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra).
